# ROADMAP

This repository will inevitably grow in size and scope. As such, I only have a few guidelines and requests, and you should check [here for contributing guidelines](CONTRIBUTING.md) and [here for the license](LICENSE.md) to be safe:

1. **Minimize directories, maximize intent**
   - Try not to over-engineer the repository too early, while making sure it's easy to grow later, and easy to find things. For example, for now, my very first practice texture map will be within `assets/`, and all of my notes will be in `src/`. As it grows, and more and more objects are added, and more and more kinds of information are added, or files get larger, I can imagine it growing into `src/solar-system/`, or `assets/texture-maps/`.
2. **A viewable website**
   - I realize this might end up being a fork of this repository, but in any case, it would be useful to bypass specific website filters, such as github, via a GitHub page or similar website hosted on a domain which wouldn't automatically get blocked, and which allows non-developers an easier way to access everything without having to deal with a developer-based UI.

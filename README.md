# open-astronomy-catalog

> A high schooler's collection of random astronomy information.
> v0.1.0

## Introduction

I have been scouring the internet and others for resources, and I thought it would be useful to compile the information I discovered for myself and any other person who doesn't want to go on a search again. This isn't exactly scientifically rigorous, however I will attempt to make sure everything is factual and clear. If something is incorrect, please leave an issue.

This repository is not meant to be a general space facts curation the common person would know or learn about. It details things in greater depth of this rabbit hole, but can be used as an on-ramp to more advanced concepts you won't usually get to see. Consider it a semi-professional educational resource, albeit one that serves as a clean collection and source finder for people who are already deep into this rabbit hole.

I do not claim to know everything, so this repository will definitely grow more robust, up-to-date, and accessible. I would love to increase my knowledge base and filter out any misconceptions or unclear concepts I currently have and _do not know of._

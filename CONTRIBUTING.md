# CONTRIBUTING

Thank you for your interest in helping catalog astronomy in this repository! I understand some of you might be intimidated by GitHub, while the rest are fine, so I have attempted to cater towards that.

Please find your group below to see how you can easily contribute.

---

## For Artists, Astrophotographers, Space Nerds, and Anyone Scared of Breaking Something

If you found an incredible texture map, want to share your own processing workflow, or noticed a mistake in our explanations, or want to add a useful fact nobody has covered, **you do not need to know how to code or use Git.** However, to keep things streamlined, it would make sense to create a **GitHub account.**

### How to Contribute via GitHub Issues:

1. Go to the **Issues** tab at the top of this repository.
2. Click the green **New Issue** button.
3. Choose a title (e.g., "Texture Link: New Saturn Map by [Author]") and describe what you want to add or change, and why.
4. Click **Submit**. The repository owner can take your info and update the repository for you!

_Note: By sharing your own textures, text, or other creative materials here, you agree to release your original work under the repository's default **CC BY-SA 4.0** license so the whole community can safely benefit from it._

---

## For People Who Get GitHub

If you are here to write **any** sort of code, or are comfortable carrying out issues or similar via Git or GitHub, please note all expectations.

1. You follow all guidelines of change mentioned in other top-level markdown files, such as [ROADMAP](ROADMAP.md), [README](README.md), etc.
2. You adhere strictly to conventional commits (e.g. `docs: add alternative text to polar JunoCam image` or `feat(guide): add example python script for calibration`).
3. You create all new commits on a new branch as `main` is protected.
4. Any documentation lists sources, authors, dates, etc. As this repository is small, I will be lenient to start off.

_Note: By submitting a Pull Request, you agree that any code or scripts you contribute will be permanently licensed under the repository's default **MIT License**. You also adhere to any terms listed above._

---

## Copyright Notice

We are a directory and educational resource. **Do not upload files that you do not own.**

If you want to share proprietary data, do not upload their actual content. Instead, submit an Issue with a **link** to their website (or contact if not possible) so we can properly catalog them without violating their copyright.
